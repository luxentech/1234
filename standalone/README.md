# 🌟 مجلد الموقع المستقل (Elevate Standalone)

هذا المجلد يحتوي على كامل ملفات الموقع وسيرفره وقاعدة بياناته بشكل مباشر ومستقل تماماً بدون أي تعقيد أو ملفات متداخلة.

## 📁 محتويات المجلد:
- `index.html`: الصفحة الرئيسية للمنصة بجميع أقسامها وتفاعلاتها.
- `login.html`: صفحة تسجيل الدخول وإنشاء الحساب المستقلة والدخول بـ Google.
- `style.css`: التنسيقات والتصميم بالكامل.
- `script.js`: البرمجة التفاعلية للموقع.
- `db-sync.js`: ملف المزامنة الحية الفورية مع السيرفر.
- `server.js`: ملف السيرفر المباشر (Node.js مدمج بدون أي مكتبات إضافية).
- `elevate.db`: قاعدة بيانات SQLite الحقيقية المجهزة ببيانات المستخدمين والفرص والمحتوى.
- `images/`: مجلد الصور وشعارات الموقع.

---

## 🚀 طريقة تشغيل الموقع:
1. ادخل إلى مجلد `standalone`:
   ```bash
   cd standalone
   ```
2. شغل السيرفر بأمر واحد فقط:
   ```bash
   node server.js
   ```
3. افتح المتصفح على:
   - **الموقع:** `http://localhost:3000`
   - **تسجيل الدخول:** `http://localhost:3000/login.html`
